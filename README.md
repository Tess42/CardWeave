A WPF desktop application for designing and visualizing tablet weaving patterns.

## Features

- Design and edit tablet weaving patterns interactively
- Visualize patterns in real-time
- Step-by-step weaving guide for physical weaving
- Save/load patterns as JSON files
- Export patterns as PNG or JPEG images

## Requirements

- Windows 10 or later
